# @lokio/types

Shared, runtime-agnostic TypeScript types for [Lokio](https://github.com/pikl-cz/lokio)
(`EntryStat`, `DirEntry`, `ChangeEvent`, `AdapterCapabilities`, ...).

You normally don't need to install this directly - every type is re-exported from
[`@lokio/core`](../core).
